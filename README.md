# Repositorio do trabalho 1 de PAA

Este é o repositorio do primeiro trabalho da disciplina de Projeto e Análise de Algoritmos, onde foram desenvolvidas as heurísticas Bottom-Left e MaxRects para o problema do Bin Packing Bidimensional (BP2D).

# Instruções de Execução

1. (opcional) crie um ambiente virtual

```sh python -m venv 
venv./venv/Scrips/activate
```
2. instale as dependências

```sh
pip install -r requirements.txt
```

2. execute no terminal:

```sh
python ./libs/main.py
```
